Each art tile is a `<button>` whose selected state is expressed purely through border/background color:

```tsx
<button
  key={art.id}
  type="button"
  onClick={() => onSelect(art.imageUrl)}
  className={`... ${selectedUrl === art.imageUrl ? "border-orange bg-orange/10" : "border-foreground/10 ..."}`}
>
```

There is no `aria-pressed` (or `aria-current`) reflecting `selectedUrl === art.imageUrl`, so a screen-reader or keyboard user cannot tell which printing is currently selected — a state relayed by color alone. This also diverges from the codebase's own convention, which uses `aria-pressed` for toggle buttons elsewhere (e.g. finish/color toggles). Fix: add `aria-pressed={selectedUrl === art.imageUrl}` to each tile.
