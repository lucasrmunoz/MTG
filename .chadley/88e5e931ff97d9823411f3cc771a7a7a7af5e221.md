In multiplayer Commander, players are eliminated mid-game while the remaining players keep going. This tracker has no concept of an eliminated seat:

- `endTurn` always advances to the next seat unconditionally, so "End turn" repeatedly lands on dead players and the user must tap through them each round:
```ts
const next = game.players[(index + 1) % game.players.length];
```
- `Player` has no `eliminated`/`out` flag, and there is no `removePlayer` helper.
- The only way to drop a player from the board is **"New game"**, which wipes the entire game:
```ts
function handleNewGame() {
  ...
  setGame(null); // resets every player, life total, and reminder
}
```

### Suggested shape
Add an `eliminated: boolean` to `Player` (defaulted in `createGame`/`parsePlayer`), let a zone's menu toggle it, dim the zone, and have `endTurn`/`setActivePlayer` skip eliminated seats when picking the next active player. This is additive and reuses the existing seat-plan rendering (eliminated players can keep their board cell, greyed out).
