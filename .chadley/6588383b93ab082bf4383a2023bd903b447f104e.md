Only the `null` case of `fetchedAt` is guarded. A non-null but unparseable ISO string makes `new Date(vendor.fetchedAt).getTime()` return `NaN`, so `minutes` is `NaN`, both `minutes < 1` and `minutes < 60` are false, and the function falls through to the final branch printing `as of ${Math.floor(NaN / 60)}h ago` → **"as of NaNh ago"**.

```ts
if (!vendor.loaded || vendor.fetchedAt === null) {
  return "loading…";
}
const minutes = Math.floor((Date.now() - new Date(vendor.fetchedAt).getTime()) / 60_000);
```

Low likelihood given the API contract, but there is no finite check.

**Fix:** guard `Number.isNaN(minutes)` (or the parsed time) and fall back to `"loading…"`/`"—"`.
