## Proposal

Turn state and reminders cross the AR bridge display-only: the AR view shows the ▶ turn marker and reminder chips but cannot change anything, so ending a turn or dismissing a fired reminder means leaving AR for the game screen. Add an end-turn control and tap-to-dismiss reminder chips inside AR.

The deliberate part is widening the bridge contract: applyArPlayers merges back only life and casts so a stale AR result can never corrupt the game. The widened payload adds activePlayerId, turn, and surviving reminder ids, merged with the same defensive posture (ignore unknown ids, clamp turn to ≥ current). Reminder creation stays web-only.

Depends only on shipped features (turn tracking, reminders, the AR bridge), so it is independently buildable now — but it changes the bridge contract in both directions, so build it as its own piece of work with the merge rules written first.
