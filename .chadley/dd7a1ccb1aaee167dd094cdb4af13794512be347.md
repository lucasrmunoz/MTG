The app's own tagline is "browse every printing," and the art-version mapper already fetches and populates `artist`, `releasedAt`, and `collectorNumber` for every printing (`toArtVersion` in `scryfall.ts`; the C# `ScryfallCardMapper` mirrors it). Yet the grid tile shows only `setName` and the price — the artist and release year, which are exactly the differentiators a user browses alternate arts for, are dropped.

**Suggestion:** display the already-available `artist` (and optionally the release year from `releasedAt`) on each tile — e.g. a small `Artist · YYYY` line under the set name, or a `title` tooltip. This is a low-cost, high-value enhancement with no new data fetching required. `page.tsx` already assembles `previewPrinting` with the collector number for the preview panel, so the pattern exists to reuse.
