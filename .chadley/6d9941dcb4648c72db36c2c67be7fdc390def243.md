`pickRandom` selects uniformly across the whole keyword list without excluding the entry currently shown in `spotlight`. Clicking "Random Keyword" therefore has a `1/KEYWORDS.length` chance of landing on the same keyword already displayed, in which case the UI does not change and the button looks broken to the user.

**Suggestion:** when `KEYWORDS.length > 1`, re-roll (or pick from the list excluding the current spotlight) so consecutive draws always change the displayed keyword.
