The foil badge renders a decorative sparkles emoji directly in text: `✨ Foil`. Screen readers announce this emoji by its Unicode name ("sparkles"), so assistive-tech users hear "sparkles Foil" instead of just "Foil". The emoji conveys no information beyond the adjacent word and should be marked decorative.

The foil state is already conveyed to assistive tech through the image alt text (`\`${alt} (foil)\``, L26), so the badge text is purely visual reinforcement. Wrapping the emoji in `<span aria-hidden="true">✨</span>` (or applying `aria-hidden` to the emoji glyph) keeps the visual badge while removing the redundant, confusing announcement.
