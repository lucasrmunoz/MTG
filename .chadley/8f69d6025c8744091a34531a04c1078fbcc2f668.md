The document metadata advertises a deck builder:

```tsx
export const metadata: Metadata = {
  title: "MTG Deck Builder",
  description: "...",
};
```

Everywhere else the app calls itself "MTG Card Lookup" (the `<h1>` in `page.tsx` is literally `MTG Card Lookup`, and the tagline is "Search Magic: The Gathering cards, browse every printing, and compare prices"). There is no deck-building feature anywhere in the codebase. The browser-tab / SEO title is therefore inaccurate and inconsistent with the product.

**Fix:** set `title` to "MTG Card Lookup" (matching the H1).
