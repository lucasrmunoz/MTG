On the game board, each player's reminders render as chips with the `truncate` class, so any reminder longer than the chip width is cut off (not even an ellipsis is guaranteed on flex children). There is no affordance to reveal the full text:

- The **due** chip is a `<button>` whose `title` is hardcoded to `"Tap when done"` — it never exposes the reminder's actual text, so hovering shows the generic action hint instead of the truncated content.
- The **non-due** chip is a plain `<span>` with **no `title` at all**, so its truncated text cannot be read by hovering either.

A player who types a longer reminder (e.g. "Sacrifice a creature at your end step if you haven't attacked") sees only "Sacrifice a creature at your…" on the board with no way to recover the rest without opening the zone menu — and dismissing the due chip to check it destroys the reminder.

Fix is small and local: set `title={reminderLabel(reminder)}` on both the due button and the non-due span (and, for the due chip, move the "Tap when done" hint to `aria-label` or append it), so the full reminder text is always recoverable on hover/long-press.
