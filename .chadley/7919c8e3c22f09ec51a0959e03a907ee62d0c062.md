The random-card feature lets users constrain by color via a WUBRG picker plus a "contains"/"only" mode. There is no way to ask for **colorless** cards specifically: with zero colors selected the code omits the color clause and draws from the entire pool, and the picker exposes no colorless option. `fetchRandomCard`'s own doc comment notes that `only` mode lets colorless *qualify* as a subset, but a user can never *target* colorless artifacts/lands directly.

**Suggestion:** add a "Colorless" toggle that maps to a Scryfall `c=colorless` / `is:colorless` query when selected. The plumbing (color list → query string) already exists and is a small, contained addition.
