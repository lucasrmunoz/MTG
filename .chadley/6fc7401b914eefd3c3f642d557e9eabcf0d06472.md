`api.ts` computes and exports a flag whose entire purpose is to let the UI explain the reduced-pricing mode:

```ts
/** True when running against Scryfall directly, so only TCGplayer prices exist. */
export const usingDirectScryfall = apiBaseUrl === undefined || apiBaseUrl === "";
```

A repo-wide search shows it is never imported anywhere. On the GitHub Pages deployment (which deliberately runs in direct-Scryfall mode), the vendor dropdown silently contains only TCGplayer, and the user is given no indication that Card Kingdom and Mana Pool exist but are unavailable in this hosting mode — they simply look absent. The flag is already wired to distinguish exactly this case; surfacing it as a small banner or note next to `PriceControls` ("Card Kingdom & Mana Pool need the API — showing TCGplayer only") is a low-risk, high-clarity improvement that the code was evidently set up for.
