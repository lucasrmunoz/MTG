The chip button uses `aria-expanded`, implying a disclosure/popup relationship, but the revealed content is a `role="tooltip"` span with no `id`, and the button has no `aria-controls`/`aria-describedby` pointing at it:

```tsx
<button type="button" onClick={() => setOpen((c) => !c)} aria-expanded={open} ...>{keyword}</button>
...
<span role="tooltip" className="absolute ...">
  <span>{entry?.name ?? keyword}</span>
  <span>{entry === null ? "This mechanic isn't in the glossary yet." : entry.definition}</span>
</span>
```

A screen reader announces the button as "expanded" but never conveys the tooltip text, because nothing links the two. `role="tooltip"` content is expected to be referenced via `aria-describedby`. Fix: give the popup an `id` and reference it with `aria-describedby` (or `aria-controls`) on the button — or switch to a proper disclosure pattern rather than a tooltip role.
