`error` is set by failed searches/random draws and is only reset at the **start** of the next `handleSearch`/`handleRandomCard`. `backToResults` — which returns from an open card to the match grid — clears card/art state but leaves `error` untouched:

```tsx
function backToResults() {
  requestIdRef.current++;
  setCard(null);
  setArtVersions([]);
  setLoadingArt(false);
  setSelectedArtUrl(null);
  setHoveredArtUrl(null);
}
```

A leftover error banner from a prior failure can therefore persist above the matches grid after in-app navigation, until the user issues a new search. Minor, since the next search clears it.

**Fix:** add `setError(null)` in `backToResults` (and arguably clear it on successful selection).
