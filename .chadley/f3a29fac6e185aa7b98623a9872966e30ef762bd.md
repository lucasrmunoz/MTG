`ReminderEditor.add()` calls `onAddReminder(phase, text)` with no check that `text` is non-empty, and the underlying `addReminder` only trims the string without rejecting an empty result. Tapping "Add" (or pressing Enter) with an empty text box creates a reminder whose label renders as just the phase name (e.g. "End step"). The user can repeatedly add unlimited placeholder reminders on a zone, each consuming a badge/row and a `nextReminderId`, with no note attached. This is distinct from the already-tracked whitespace-only *restored* reminder issue — this one is created live via the editor.

**Fix:** guard `add()` with `if (text.trim() === "") return;` and/or disable the Add button while the text is blank.
