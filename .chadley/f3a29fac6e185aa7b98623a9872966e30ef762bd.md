`ReminderEditor.add()` forwards `text` to `onAddReminder` unconditionally: the "Add" button is never `disabled`, and the Enter-key handler also calls `add()` with no check. Downstream, `addReminder` trims to `text: ""` and `reminderLabel` then renders only the phase word (`"End step"`, `"Upkeep"`, …) when the text is empty.

The result is that a user can create any number of empty reminder chips that convey no actual instruction, cluttering the zone footer (and, per the app's design notes, the AR reminder display which mirrors these). A simple `text.trim() === ""` guard on `add()` (and matching `disabled` on the button) prevents it.

This is a distinct symbol and data path from the already-known empty-player-name validation gap.
