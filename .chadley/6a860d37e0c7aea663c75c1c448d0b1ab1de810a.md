Each art tile is a focusable `<button>`, but the preview panel is updated exclusively through `onMouseEnter`/`onMouseLeave` (`ArtVersionGrid.tsx:73-74`). There are no `onFocus`/`onBlur` handlers.

Consequences:
- **Keyboard users** can Tab to a tile and press Enter to select it (`onClick` works), but the hover preview panel never updates as they move focus, so the preview feature is entirely unavailable without a pointing device — an accessibility gap.
- **Touch users** often fire `mouseenter` on tap but never a matching `mouseleave`, leaving the preview stuck on a previously-tapped version that no longer matches the selection.

**Fix sketch:** add `onFocus={() => onHover(art.imageUrl)}` and `onBlur={() => onHover(null)}` mirroring the existing hover handlers so keyboard focus drives the preview and provides a deterministic reset path.
