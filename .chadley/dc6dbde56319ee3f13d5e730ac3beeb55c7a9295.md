`CardDetail` renders `card.keywords` once at the card level, while rendering oracle text per face for DFCs:

```tsx
{card.keywords.length > 0 && (
  <DetailRow label="Keywords">
    ...{card.keywords.map((keyword) => <KeywordChip .../>) }...
  </DetailRow>
)}

{card.faces.length > 0 ? (
  <DetailRow label="Card Text">
    {card.faces.map((face) => ( ... face.name / face.oracleText ... ))}
  </DetailRow>
) : ( ... )}
```

For a modal/transform card the combined keyword set is presented as if the whole card has every keyword — e.g. a front-face creature with Flying plus a back-face planeswalker's keywords all appear together with no indication which face owns which. This is distinct from the known "DFC shows no P/T and no per-face mana cost" item, which concerns P/T and mana cost, not keywords.

**Fix direction:** Attribute keywords per face (surface them inside each face block alongside the oracle text), or hide the card-level keyword row for multi-face cards.
